# Feedback and suggestions

[中文](CONTRIBUTING.md) · English

Please use [Issues](https://github.com/Lewis-18/StatM/issues) to report problems or suggest improvements.

For a problem, provide the StatM version, Windows version, steps, selected variables and parameters, and expected versus actual results. Prefer a built-in dataset for reproduction; attach anonymized screenshots or a minimal dataset when needed.

For a feature request, explain the workflow, the difficulty and the operation you would like. Do not include personal information, sensitive data or credentials in public feedback.
