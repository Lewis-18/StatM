# StatM

**让数据，抵达洞见。**

StatM 是面向学习与研究的 Windows 离线统计分析工作台，将数据导入、探索、统计分析和科研绘图放在一个连续的工作空间中。

**维护者：Jackson Lewis** · **当前产品版本：1.8.0** · **平台：Windows x64**

> 当前仅开放产品介绍与界面预览，**安装包暂未开放下载，APP 源码不公开**。本仓库的 “Code → Download ZIP” 仅包含介绍资料与图片，不是 APP 安装包或开发源码。

![StatM 深色首页](assets/home-dark.png)

## 可以做什么

- **整理数据**：导入 CSV、XLSX、XLS，预览、搜索、筛选并生成清洗后的数据版本。
- **开展统计分析**：描述统计、相关分析、常见假设检验、线性回归与主成分分析。
- **制作科研图表**：分布、相关、回归诊断、二维与三维探索图表，导出 PNG 与 SVG。
- **保存研究进度**：项目、参数草稿、分析历史与图表保存在本机，支持恢复和重跑。
- **查看分析步骤**：针对用户数据生成 Python / R 分析脚本；这些分析脚本与 APP 开发源码是不同内容。

核心分析在本机运行，无需另外安装 Python 或 Node.js。公开示例数据随桌面版提供；联网仅用于主动使用的在线功能，例如检查版本。

## 1.8.0 界面预览

首页围绕导入数据、开始统计任务、最近项目和继续分析组织。青蓝与冷银视觉配合数学曲面、粒子开场和金属 M 等待动效，支持深浅主题及减少动画偏好。
