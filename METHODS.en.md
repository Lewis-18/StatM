# StatM 1.4.0 methods and validation

Reliability uses raw-score Cronbach alpha, Feldt intervals, corrected item-total correlations and alpha after deleting each item. Every diagnostic uses the same complete-case sample. Reverse scoring requires explicit bounds and item selection. Numerical checks compare the results with [Pingouin](https://pingouin-stats.org/generated/pingouin.cronbach_alpha.html); interval values are retained at full precision.

EFA uses the Gaussian maximum-likelihood common factor model in [scikit-learn FactorAnalysis](https://scikit-learn.org/stable/modules/generated/sklearn.decomposition.FactorAnalysis.html), with deterministic LAPACK, no rotation or orthogonal Varimax. Variables use sample-SD standardization; ML loadings and unique variances are rescaled to the sample correlation scale. KMO and Bartlett use all complete cases. Correlation-eigenvalue parallel analysis uses 100 column-wise permutations, the 95th percentile and seed 937; a fixed sample of at most 5000 rows is used for this diagnostic while fitting uses all complete cases. The user specifies the factor count. Singular matrices, underidentified models and nonconvergence stop the calculation. Boundary solutions and small samples are flagged. This is distinct from PCA, CFA and polychoric analysis.

Batch comparisons report valid counts and missingness per mapped field. Numeric distance is [SciPy Wasserstein-1](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.wasserstein_distance.html) in the original units; categorical distance is total variation. No independent-sample p-values, rankings across units or universal anomaly thresholds are supplied. Known dictionary unit or code conflicts stop the comparison; incomplete definitions require explicit user confirmation. Histograms share bins over the combined range and show proportions within each valid batch. Python and R references preserve literal category codes; the bundled Python runner is the numerical verification entry point.

Faceted scatterplots and histograms share axis ranges and bin edges. Scatterplots display at most 2000 fixed-seed records per group, preserving small groups. Counts and sampled counts are reported per panel. Figure specifications persist in history and in exported reproduction bundles. Word tables, vector SVG/PDF and 300 DPI PNG are checked in the desktop workflow.

Automated checks cover reverse scoring, complete-case intervals, recovery of a synthetic two-factor structure, covariance invariance under orthogonal rotation, singular and underidentified models, shared histogram counts, small groups, category semantics, API history and independent reproduction. Synthetic data are used throughout. Tests on the current Windows host do not constitute a clean virtual-machine installation test.
